Privacy Policy for PDF to Gmail

Last updated: May 05, 2026

PDF to Gmail is a Chrome extension that allows the user to send the currently opened PDF file as an email attachment through their Gmail account.

Data Collection

This extension does not collect, sell, share, or transmit personal data to any external server operated by us.

The extension processes the currently opened PDF only when the user explicitly clicks the Send PDF button.

Use of Gmail

The extension uses the official Gmail API only to send an email with the selected PDF attachment from the user's authenticated Gmail account.

The extension does not read, access, scan, store, or analyze the user's Gmail inbox, email history, contacts, or email content.

Locally Stored Data

The extension may store recently used recipient email addresses locally in the user's browser using Chrome local storage. This is used only for autocomplete convenience.

This locally stored data remains on the user's device and is not transmitted to us or to any external server.

PDF Files

PDF files are downloaded temporarily by the extension only for the purpose of attaching them to the email selected by the user. The extension does not permanently store PDF files.

Third-Party Services

The extension uses Google OAuth and the Gmail API provided by Google. Use of these services is subject to Google's Privacy Policy:

https://policies.google.com/privacy

Children's Privacy

This extension is not intended for children under the age of 16. We do not knowingly collect personal data from children.

Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be posted on this page.
